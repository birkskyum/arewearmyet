# HP OmniBook 3 16 (16-bz0) device tree

`x1p42100-hp-omnibook-3-16.dts` is the file Omarchy's kernel builds for the HP OmniBook 3
16-bz0xxx, from patch `2744` at omarchy-pkgs
[`643e5ef`](https://github.com/omacom/omarchy-pkgs/tree/643e5efb14222497ead51ea1f909db8d40a2b6d4/pkgbuilds/linux-omarchy-aarch64)
(omacom/omarchy-pkgs#2263). It includes the OmniBook 3 14's `x1-hp-omnibook-3.dtsi`, in
`../hp-omnibook-3-14-hz0/`.
